# Qoder IDE

host 固定为 qoder。目录安装候选为用户 .qoder/skills/digital-employee-connect；必须在当前 Qoder IDE 版本中验证原生发现和加载，不能将旧目录文档当现场证据。不将 QoderWork、CLI 或其他宿主代入。

使用原生导入方式或先 plan 再 install。成功后在新任务中原生选择此 Skill，再运行 connect。设备身份与 Kimi 分开，绑定保存在当前 Windows 用户 LocalAppData/DigitalEmployee/qoder，自有便携包在 LocalAppData/DigitalEmployeeClient。

用户本人在网页中确认设备、员工和任务权限。Qoder 仅消费 [helper turn](native-helper.md)，不得直接执行员工浏览器业务。保留 Qoder 的原生工具审批，不修改全局权限或自动记忆设置。nativeActivation=NOT_VERIFIED 是真实宿主验收未完成的状态。
